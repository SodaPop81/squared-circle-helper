# Squared Circle Helper v0.8.0

Adds:

- WarGames entrance order output
- Survivor Series elimination order showing who eliminated whom
- Survivor(s) summary
- These details appear in the match log and Notable Events

Build:

```bash
rm -rf node_modules package-lock.json dist
npm install
npm run build
```

Upload the contents of `dist/` to Netlify/GitHub Pages.
